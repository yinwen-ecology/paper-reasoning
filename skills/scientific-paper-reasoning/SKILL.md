# Scientific Paper Reasoning

用论文证据重建科学推理，而不是按 Background–Methods–Results–Discussion 复述内容。核心问题是：**作者为什么必须做下一步？** 优秀故事使下一个问题、分析或实验显得必然；结果可以出乎意料。

## 使用与材料

- 面向单篇已发表论文的深度阅读；用户要求比较多篇时，先逐篇重建，再比较其问题、判别证据与 claim 边界。
- 优先读全文、图表及图注；关键判断需要时检查方法与补充材料。标明具体 Figure、结果段或方法依据，并区分“作者明确声称”和“我的推理重建”。
- 只有摘要时，可以判断候选问题和表层论证，但不可臆造竞争解释、决定性图、因果机制或作者意图；明确指出哪些判断待全文验证。材料不足不妨碍给出**现有材料所允许的明确结论**。
- 有全文且用户未要求短版时，默认提供能让读者跟上推理的**深度分析**。只有用户明确要求简短诊断，或材料仅有摘要时，才压缩展开；仍须显示实际问题与回答。

## Codex / GPT-6.1 sol 的执行方式

以 Codex 中的 GPT-6.1 sol 为目标环境。推理强度、模型选择和可用工具由客户端决定；本 Skill 规定分析行为与交付质量。执行需要全文获取、长文分段读取、图表核验或 Markdown 文件交付时，按需读取 [codex_workflow.md](references/codex_workflow.md)。单纯修订一段既有分析时，直接使用已核对材料。

先建立简洁的“主张—关键结果—来源位置”工作记录，再据此成文。复杂论文先核对决定中心判断的几项证据，随后重建元问题与六拍；不要在尚未读到关键方法时，凭题目或摘要写完漂亮的故事。长文可保存来源摘录与工作记录以便跨轮继续，正文只展示理解判断所需的证据与推理。

## 核心工作流

完整分析前，阅读 [scientific_reasoning_framework.md](references/scientific_reasoning_framework.md) 的判据与输出模板，并按论文类型调整证据标准。

1. **定位问题与张力。** 用一句话写 central scientific question，明确研究前的具体 field belief 或可靠预期，以及尚未解决的张力或关键可观测性问题。区分数据、方法、经验和概念缺口；不要强造 conceptual gap。“首次”“最大”本身不证明问题重要。
2. **通过 Tractability Gate。** 检查概念到测量的对应、关键变异和尺度、竞争解释的不同预测、可辨识性、成功与否定标准。判断研究设计实际能回答问题的哪一部分。
3. **建立证据架构。** 列出主要竞争解释及预测，确定哪个实验、比较或证据组合真正区分它们。执行删除检验：去掉哪项结果 central claim 会明显削弱？写出什么结果会改变结论，什么结果会迫使放弃首选解释。可明确判定“没有单一决定性结果”，并指出最小必要证据组合。若论文有两个相连但不同的核心 claim，分别标明证据瓶颈。
4. **校准 claim。** 找到证据支持的最大判断，用一句肯定句说出来。把相关、预测、机制与因果的语言和设计匹配；只在读者可能误读的关键跃迁处交代边界，一处说透，不逐段重申。再用这个判断修正论文真正的 conceptual contribution。
5. **重建六拍与五个箭头。** Field belief → tension → approach → decisive evidence → new understanding → consequence。前两拍尤其要展开：先写研究开始前已有的具体认识、各自的证据尺度与自然推论，再写认识在何处接不上。存在真实竞争解释时讲清它们的不同预期；发现型研究可围绕关键现象尚不可观测或尚未跨尺度检验展开。严格区分**研究前的问题**和**论文结果揭示的意外**，不要把后面的图或发现倒填成研究动机。后四拍说明设计怎样回答悬念、证据怎样改变判断、又逼出什么下一问。
6. **检查论证与写作。** 将每张主要图标成建立现象、排除解释、检验机制、界定边界、推广、稳健性或后果；检查 Introduction、Results、Discussion 是否服务同一个问题。最终提炼 3–7 条跨研究系统可迁移的 research principles。

## 输出约束

- **先给主判断，再明确列出精选元问题。** 开头用一段话说清这篇论文最重要的认识及关键证据。完整分析须逐题显示“元问题 1：真正的科学问题是什么？”“元问题 2：为什么重要？”“元问题 3：建立了什么新认识？”，每题标题下以 **“回答：”** 开始，给出明确结论和展开的推理；这三题的答案不能只藏在导语或六拍里。其余从元问题 4–8 和 Tractability Gate 中按论文选择，不必凑齐全部；入选者同样显示编号、完整问题和回答。避免用“核心判断”表格把答案预先拆成许多格子。
- **回答必须展开推理。** 每个入选问题都要讲清结论、关键结果及其科学意义；当替代解释会改变答案时，再比较它们。复杂问题可用数段和小表格，不能只写一句判断或一串关键词。读者应看得出“为什么”，不必自行补齐推断链；不必让每个回答都包含一段限制或反驳。
- **让读者读懂推断的中间一步。** 默认读者有科研基础，但未必熟悉本论文的细分领域。关键术语首次出现时解释它测量什么、数值方向意味着什么；涉及负值、差值、比例或尺度转换时，可用一个明确标为示意的简短例子帮助理解。每项中心证据交代比较对象、独立分析单位、结果及其为何改变判断。公式、统计名词和图号不能代替这层解释；完整问答须让读者能复述“作者比较了什么，为什么这个结果支持结论”。
- **把方法审查落实到中心结果。** 检查关键指标的测量是否对应所讨论概念，以及核心统计比较是否真的检验了所声称的差异。候选指标的显著性筛选、模型间的直接比较与独立样本预测是不同证据；多个由同一数据计算的结果也不自动构成独立机制验证。只展开影响中心判断的具体检查。若声称推翻领域旧认识或建立全新概念，核对关键前序研究，区分本系统的新证据与概念本身的新颖性。
- **六拍展开，补充栏目按需。** 第一拍和第二拍讲清已有认识、推断缺口与竞争预期，第三拍说明设计怎样回答悬念；各拍篇幅由推理复杂度决定。问答解释问题与证据，六拍解释论证如何推进，避免逐字复述。额外的证据表、claim ladder 或图序须带来新信息。
- **段落承载推理。** 用连贯段落写“发现—解释—下一问”。问题标题和“回答：”保留；变量、短语与箭头不单独占行。保留必要公式与对照表，避免密集断行、整齐但空洞的套话转场。
- **观点鲜明，边界集中。** 先说“这篇论文改变了什么认识”，再给关键图和推理。直接指出最值钱的证据与最弱的推断，但不要把每段都写成“强结论＋但是＋尚未证明”。若一个限制只影响因果、外推或某个具体措辞，把它放在讨论该跃迁的一个位置讲清，其他地方继续使用成立的强判断。避免列举一串想象中的混杂因素、反复提醒观察研究不能证明因果、把“不能”当作主要修辞动力。
- **结构让位于理解。** 不用“核心判断 / 证据架构 / claim ladder / 图序 / 最终综合”固定套餐，也不把同一句主张反复写进各栏目。框架术语只有提高解释力时才进入正文；明确元问题编号是读者导航，答案的内容和句式随论文变化。
- **尊重阴性与复杂结果。** 显著性、效应大小和技术复杂度不自动等于决定性证据；可识别多项证据合力。若论文没有真正排除竞争解释，直接说清缺哪项判别证据，同时保留已经可靠建立的认识。
- **避免摘要化与清单化。** 不逐段复述作者做了什么，不把 Results 的发表顺序等同于推理顺序，不平均分配篇幅，不凭期刊声望赞美或贬低，不做数字评分、顶刊概率预测或机械关键词匹配。

交付前回看中心结论与关键图、方法是否一致，再以不熟悉该细分领域的研究者视角通读：是否懂指标方向，能否跟上比较，能否复述认识为何改变？直接修正跳步、来源不明的强判断和重复段落。用户要求完整 Markdown 时，实际保存文件并提供可打开的链接。
